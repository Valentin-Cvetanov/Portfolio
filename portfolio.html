Featured Project

MaystorX

A full-stack marketplace connecting customers with local service professionals.
The platform allows professionals to create and manage service listings, while customers can discover services through location-based search and filtering.

Built with ASP.NET Core MVC, PostgreSQL, Tailwind CSS, and JavaScript, the application features cookie-based authentication, email and SMS verification through Brevo, image uploads with compression and optimization, AI-assisted listing descriptions, and dedicated profiles for service professionals.

The application is deployed on a Linux VPS using Nginx as a reverse proxy, with HTTPS enabled for secure communication.

About Me
